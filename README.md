# TNT Bow Arsenal

TNT Bow Arsenal is a Minecraft plugin for Paper servers that adds a custom TNT Bow with explosive TNT arrows and throwable TNT charges. Players can shoot explosive arrows using the bow normally or sneak and right-click to throw a TNT-themed projectile that explodes on impact. The plugin provides a dedicated command and permission system for obtaining and using the TNT Bow.

## Install

1. Make sure your server runs Paper 1.21.11 or a compatible version and Java 21.
2. Download or build the plugin JAR file.
3. Place `plugin.jar` in your server's `plugins` folder.
4. Start or restart the server to load the plugin.
5. Make sure you have the `tntbow.use` permission to obtain the TNT Bow.

## Use

1. Join your Minecraft server.
2. Run `/tntbow` to receive the TNT Bow.
3. Equip the TNT Bow and shoot normally to fire explosive arrows.
4. Sneak and right-click while holding the TNT Bow to throw a TNT charge.
5. Projectiles explode when they hit something, creating an explosion with a power of 3.0.
6. Give other players access by granting them the `tntbow.use` permission.

The command is available to server operators by default.
